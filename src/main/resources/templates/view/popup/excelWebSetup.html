ActiveX 수동 설치

ebay SMS 발송 WEB 이용시 ActiveX 설치가 자동으로 설치되지 않는 경우 아래와 같이 조치하여 주시기 바랍니다.

<조치방법>

  1. [파일열기] 버튼을 클릭한 후, [실행] 버튼을 클릭하여 프로그램을 실행하십시오.
  2. 파일 다운로드 - 보안경고 창에서 [실행] 버튼을 클릭하여 프로그램을 실행하여 주십시오.
  3. ExcelWeb ActiveX 설치 화면에서 [다음] 버튼을 클릭하여 프로그램 설치를 진행하십시오.
  4. ExcelWeb ActiveX 설치 화면에서 [설치시작] 버튼을 클릭하여 프로그램 설치를 진행하십시오.
  5. ExcelWeb ActiveX 설치 화면에서 [확인] 버튼을 클릭하여 프로그램 설치를 종료하십시오.
